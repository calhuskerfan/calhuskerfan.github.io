> Connecting SRQC to a Message Queue Service

This post extends the queue consumer pattern [discussed here]({% post_url 2025-09-28-SQRC %}) to connect to a message brokering service.  This implementaion utilizes [RabbitMQ](https://www.rabbitmq.com/).

Two queues will be used, one for inbound message handling and one for outbound message Handling.  These queues will be operating as [Message Channels](https://www.enterpriseintegrationpatterns.com/patterns/messaging/MessageChannel.html).  One channel is reponsible for the producer to handler inbound and the other is responsible for the handler outbout to consumer.

![image]({{ site.baseurl }}/assets/images/srloader-part2.drawio.png)

## Operation

The system consists of the following components

| Component | Description |
|-----------|-------------|
| Message Producer | Console application that produces a configurable number of messages and Publishes them to the Inbound Queue
| Inbound Queue | A typical inbound queue in a Message Orientated Middleware (MOM) style application.  A RabbitMQ Queue in this system.|
| Message Processor | Component that receives Messages from the Inbound Queue, handles the SRQC libraries as described [here]({% post_url 2025-09-28-SQRC %}) and Publishes the results to the OUtbound Queue.
| Outbound Queue | A typical outbound queue in a Message Orientated Middleware (MOM) style application.  A RabbitMQ Queue in this system.
| Message Consumer | Responsible for Handling Messages in the Outbound Queue
